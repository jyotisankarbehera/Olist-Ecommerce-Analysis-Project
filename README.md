# Brazilian E-Commerce Data Analysis Using Python

## Project Overview

This project focuses on analyzing the Brazilian E-Commerce Public Dataset by Olist using Python. The objective is to explore sales performance, customer behavior, product categories, payment methods, seller performance, and delivery trends.

The project uses data analysis and visualization techniques to identify meaningful business insights and understand e-commerce performance.

## Project Objectives

- Analyze overall e-commerce sales performance.
- Identify top-performing product categories and products.
- Understand customer purchasing behavior.
- Analyze payment method preferences.
- Evaluate seller performance.
- Examine order delivery time and delivery performance.
- Present business insights through data visualization.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Information

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

The dataset contains information about orders, customers, products, sellers, payments, and deliveries.

The analysis was performed using a combined dataset containing approximately 113,390 records and 39 columns at the beginning of the project.

## Key Business Insights

1. **Customer Distribution:** São Paulo (SP) had the highest number of unique customers, with 38,641 customers.

2. **Popular Product Category:** Bed, Bath & Table was the leading product category by order count.

3. **Payment Preference:** Credit Card was the most frequently recorded payment method.

4. **Top Product Performance:** The highest-revenue product generated approximately BRL 68,160 in sales.

5. **Average Delivery Time:** The average delivery time was approximately 12 days.

6. **Delivery Performance:** Most delivered orders arrived on or before their estimated delivery dates.

7. **Customer Behavior:** The analysis identified new and repeat customers based on their order history.

## Data Visualization

The project includes visualizations such as:

- Top 10 Product Categories by Sales
- Monthly Sales Trend
- Year-wise Sales Performance
- Customer Distribution by State and City
- New vs Repeat Customers
- Payment Method Distribution
- Delivery Time Analysis
- Top Sellers by Revenue
- Correlation Heatmap
- Product Price Distribution

## Project Limitations

- Product cost information was not available, so actual profit and loss could not be calculated.
- Product names and seller names were not available for all records.
- The analysis is based on historical data.
- Multiple rows may belong to the same order, so appropriate grouping and deduplication methods were used for order-level analysis.

## Conclusion

This project provided practical experience in data cleaning, data analysis, and data visualization using Python.

It helped identify important patterns in customer behavior, sales performance, product categories, and delivery operations.

Overall, the project demonstrates the use of Python libraries to convert raw e-commerce data into meaningful business insights.
